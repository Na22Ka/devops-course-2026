## Что удобнее в VS Code

1. **Визуальный diff** — сразу видно, какие строки добавились и удалились,
   не нужно читать вывод `git diff` в консоли.
2. **Панель Source Control** — все изменения перед глазами, файлы можно
   добавлять в индекс кликом, а не командой `git add`.
3. **Встроенный merge-редактор** — при конфликтах есть кнопки
   «Accept Current / Incoming / Both», не нужно вручную править маркеры.
